# Images OG - À générer

Ce fichier doit contenir une image PNG avec ces spécifications :

**Dimensions:** 1200x630 pixels
**Format:** PNG
**Chemin:** `/public/og-image.png`

**Contenu recommandé:**
- Arrière-plan: Couleur primaire de votre site (#f5f0eb ou dégradé)
- Texte: "Ziky Versari" en gros
- Sous-titre: "Clown • Cirque • Pédagogie"
- Logo/Icône: Votre icône personnalisée

Vous pouvez:
1. Créer l'image avec Figma, Photoshop, ou un outil en ligne
2. Utiliser une IA pour générer l'image
3. Utiliser un générateur d'OG images: https://og-image.vercel.app/

L'image actuelle est un placeholder. Remplacez-la par votre vraie image OG une fois créée.
